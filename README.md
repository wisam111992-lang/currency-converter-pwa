# محول العملات

تطبيق ويب خفيف (PWA) لتحويل بين العملات:

- الأساس المثبَّت: الدولار الأمريكي (USD) والدينار العراقي (IQD) فقط
- **عملات العالم** (اختيارية): التومان (TOMAN) أولها، ثم +65 عملة (اليورو، الريال السعودي، الجنيه المصري، الين…) يضيفها المستخدم يدويًا بسعرها مقابل الدولار
- **وضع ليلي/نهاري**: زر في الهيدر، يُحفظ محليًا ويبقى بعد إعادة الفتح

أسعار الصرف يُدخلها المستخدم ويحفظها محليًا. **لا يوجد أي اتصال بالإنترنت للأسعار**، ولا Backend، ولا قاعدة بيانات، ولا تسجيل دخول. بعد أول تحميل يعمل التطبيق بالكامل Offline ويُثبَّت على الشاشة الرئيسية.

## التشغيل

يجب تشغيله عبر خادم محلي (Service Worker لا يعمل من `file://`):

```bash
cd currency-converter
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

أو:

```bash
./start.sh
```

## نموذج أسعار الصرف

كل الأسعار مخزّنة مقابل الدولار:

```
1 USD = IQD        (إلزامي — يُطلب في أول تشغيل)
1 USD = TOMAN      (اختياري — يُضاف من الإعدادات إن أراد)
1 USD = EUR        (اختياري — عند إضافته من الإعدادات)
1 USD = SAR        (اختياري)
...
```

أي زوج آخر يُشتق تلقائيًا عبر USD كاعدة: `X → USD → Y`.
مثال: `92 EUR` = `100 USD` = `375 SAR` (عند `1 USD = 3.75 SAR`).

**عملات العالم تُفعَّل عند الطلب فقط:** لا تظهر في قائمة التحويل إلا بعد حفظ سعر لها،
فلا تُطلب من المستخدم إدخال مئات الأسعار دفعة واحدة.

## الاختبارات

```bash
node tests/conversion.test.mjs   # 37 اختبار
node tests/storage.test.mjs      # 20 اختبار
```

يشمل سيناريو الاختبار الأساسي:

- `2,000,000 TOMAN` → `20 USD` و `30,000 IQD`
- `30,000 IQD` → `20 USD` و `2,000,000 TOMAN`
- الاتجاهات الستة + عملات العالم (EUR/SAR/JPY) + التحقق من المدخلات + التنسيق.

## التخزين المحلي

| المفتاح | المحتوى |
|---|---|
| `currency_converter.rates.v1` | `{ rates: { IQD, ...world }, updatedAt }` |
| `currency_converter.history.v1` | آخر 10 تحويلات |
| `currency_converter.theme.v1` | `'dark'` أو `'light'` |

يبقى بعد إغلاق التطبيق وإعادة تشغيل الجهاز، ولا يُرسل لأي سيرفر.
البيانات القديمة (كانت USD+IQD+TOMAN إلزامية) تُحمَّل دون أي مشكلة.
